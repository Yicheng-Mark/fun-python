# 🎉 有趣的一些 Python 小项目

一组用 Python 写的节日祝福 / 趣味动画小程序，基于 `turtle`、`tkinter`、`pygame` 做的图形动画，适合送给朋友或自己玩。

## 📦 环境要求

- Python 3.8 及以上
- 只有「跨年倒计时烟花」需要额外安装 `pygame`，其余项目均使用 Python 标准库

## 🔧 安装依赖

```bash
pip install -r requirements.txt
```

## 📂 项目列表

| 文件 | 说明 | 运行命令 |
| --- | --- | --- |
| 爱心.py | 用 turtle 画一颗红色爱心 | `python 爱心.py` |
| 玫瑰花.py | 用 turtle 绘制一朵带叶子的玫瑰花 | `python 玫瑰花.py` |
| 弹窗.py | tkinter 满屏随机温馨提示弹窗（默认 500 个） | `python 弹窗.py` |
| 烟花.py | tkinter 黑色夜空自动烟花动画 | `python 烟花.py` |
| 跨年倒计时烟花.py | pygame 跨年倒计时 + 烟花，自动指向下一个新年 | `python 跨年倒计时烟花.py` |
| 圣诞节1.py | 用 turtle 绘制绿色圣诞树与装饰 | `python 圣诞节1.py` |
| 圣诞节2粉色.py | 用 turtle 绘制粉色圣诞树与装饰 | `python 圣诞节2粉色.py` |

## ⚠️ 注意事项

- **弹窗.py** 默认弹 500 个窗口，运行起来较占资源，可在代码中 `window_count` 处调小数量。
- **跨年倒计时烟花.py** 会自动倒计时到下一个 1 月 1 日 0 点；跨年后自动显示「新年快乐」并放烟花。
- **跨年倒计时烟花.py** 字体在 Windows 上使用系统微软雅黑；若在 Mac / Linux 上运行会自动回退到默认字体，中文可能显示为方块（不影响运行）。
- 这些都是**图形界面程序**，需在有桌面环境的电脑上运行，纯命令行服务器上无法显示窗口。
